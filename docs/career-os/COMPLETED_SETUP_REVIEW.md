## What it is
Candidate Home opens with a seven-day window and links to Resume and profiles, Review setup, and Resume Studio.

## Why it exists
You can inspect and edit saved setup without repeating account creation or starting onboarding again.

## How to use it
Open Review setup from Home. Choose a completed step to inspect or edit it. Saved search preferences and active strategy values are loaded into the forms. Save the current step; review remains on that step. Use Back to home when finished. Resume and profiles opens the resume step, with saved job-platform links available in the same navigation. Resume Studio opens the resume editor.

## Common problems
Zero matches means no ready vacancies in the selected time window, not an empty discovered-job database. Some accounts have fewer setup steps because AI configuration or strategy is managed by the platform. Replacing a resume can require confirmation again.
